# Flying Frames (@flyingframes.studio)

Agencia de contenido. Todas las marcas de esta carpeta son clientes de Flying Frames:
la agencia prepara, graba y edita su material.

## Tono de la casa (por defecto para todos los clientes)
Mezcla de enérgico y divertido + profesional + cercano. Cada cliente ajusta la proporción
en su propio archivo. Nada es rígido: si el cliente pide otra cosa, manda el cliente.

## Nuevo cliente
Copia `_plantilla.md` como `nombre-del-cliente.md` y rellénalo, o usa el comando
`/nueva-marca` en Claude Code para que te haga las preguntas.
